# People Who Changed Interfaces 🗺️

## The Map

Some people change what computers can do. Others change what computers feel like to use. This trail is for the second group: the interface shapers.

## Existing Cabinet Stops

- [Douglas Engelbart](../people/others-to-research.md): mouse, demos, augmentation, the "computer as thinking partner" direction.
- [Shigeru Miyamoto](../people/shigeru-miyamoto.md): playful interaction, readable worlds, teaching through level design.
- [Evan You](../people/evan-you.md): Vue and the ergonomics of approachable frontend architecture.
- [Brendan Eich](../people/brendan-eich.md): JavaScript, for better and worse, became the interface language of the web.
- [Margaret Hamilton](../people/margaret-hamilton.md): software reliability before software had fully learned to wear a name badge.

## Pattern

Great interfaces usually lower the cost of intention. They make "I want to..." travel a shorter distance before the system understands.

That can mean a mouse, a reactive component model, a forgiving game tutorial, or a programming language already waiting in the browser.

## Why It Is Interesting

Interfaces are philosophy with buttons. Every design quietly answers: what is the user allowed to think, see, try, break, and recover from?
